# Style imitation

- The user's new premise, characters, facts, and direction remain authoritative. The reference supplies craft evidence, not story content.
- Extract transferable features such as narrative distance, sentence movement, paragraph rhythm, dialogue density, sensory selection, imagery behavior, humor, and information release.
- Do not reuse source names, distinctive phrases, scene order, plot combinations, or recognizable passages.
- Turn the analysis into a concise operational style guide with positive instructions and a few source-grounded observations.
- Apply the guide flexibly so the new work reads coherently rather than as a sentence-by-sentence costume.
